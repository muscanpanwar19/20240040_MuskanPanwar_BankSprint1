class CustomerController

MVC Architecture Controller
Summary: Controller in the Model-View-Controller (MVC) architecture that coordinates all business logic, customer and account collections, intra-account money transfers, and JSON data persistence. Strictly isolates state management and financial rules from presentation layers.

Core Properties

PropertyTypeDescription
CustomerCountintTotal number of registered customers currently managed by the controller.
PersistenceFilePathstringThe relative or absolute file path used for JSON state serialization (default: "bank_data.json").

Public Methods & Signatures

Customer CreateCustomer(string customerNumber, string name, string contactDetails, bool isStaff)

Creates a new customer, pre-populates their standard Everyday, Investment, and Omni accounts, and registers them in the system collection.

ParameterTypeDescription
customerNumberstringUnique alphanumeric customer identifier.
namestringFull legal name of the customer.
contactDetailsstringContact email address or telephone number.
isStaffboolTrue if customer qualifies for Bank Staff benefits (50% fee discount); otherwise false.
Returns: The newly created and registered Customer instance.
Throws: ArgumentException if id/name is empty; InvalidOperationException if id exists.
Account AddAccount(string customerNumber, string accountType, string accountNumber, decimal initialBalance, decimal interestRate, decimal overdraftLimit)

Dynamically creates and attaches a new account to an existing customer at runtime. Supports polymorphic creation of Everyday, Investment, and Omni accounts (Task 3: 1:N Architectural Expansion).

ParameterTypeDescription
customerNumberstringTarget customer identifier.
accountTypestringClassification type: "Everyday", "Investment", or "Omni".
accountNumberstringUnique account code (validated across entire bank).
initialBalancedecimalOpening deposit amount (must be non-negative).
interestRatedecimalAnnualized interest percentage for Investment and Omni accounts.
overdraftLimitdecimalApproved credit overdraft buffer for Omni accounts.
Returns: The newly created Account instance.
Throws: KeyNotFoundException if customer not found; ArgumentException on duplicate account number or invalid inputs.
bool Transfer(string customerNumber, string sourceAccountNumber, string destinationAccountNumber, decimal amount)

Executes an intra-account money transfer between two accounts owned by the specified customer. Resolves account references and delegates to the core transfer engine.

ParameterTypeDescription
customerNumberstringThe customer identifier who owns both accounts.
sourceAccountNumberstringAccount from which funds are debited.
destinationAccountNumberstringAccount to which funds are credited.
amountdecimalPositive monetary transfer amount.
Returns: True if transfer completes successfully.
Throws: KeyNotFoundException, BankingException, InsufficientFundsException.
bool Transfer(Customer customer, Account sourceAccount, Account destinationAccount, decimal amount)

Core intra-account transfer business logic. Enforces ownership validation, positive amounts, distinct source/destination accounts, and triggers withdrawal with account-specific overdraft/fee calculations before crediting destination.

Returns: True if transfer succeeded.
Throws: InsufficientFundsException if overdraft/balance breached (charges $10 regular, $5 staff); BankingException if rules violated.
void SaveToFile(string? filePath = null)

Serializes all customer records and polymorphic account graphs into indented JSON format and writes to local storage. Automatically executed during application exit (FormClosing).

bool LoadFromFile(string? filePath = null)

Reads JSON storage, deserializes polymorphic accounts with exact derived types, and reconstructs parent customer back-references. Automatically executed on application launch (FormLoad).

Returns: True if file exists and was loaded; false otherwise.
